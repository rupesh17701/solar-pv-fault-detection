# Solar PV Fault Detector

A CNN that classifies solar panel photos as **Clean** or **Defect** (bird
drop, dust, electrical damage, physical damage, or snow cover), served as
a small FastAPI web app.

Adapted from a standalone training script (`reference_original_script.py`)
into a trainable pipeline (`app/train.py`) plus an inference service
(`app/main.py`), containerized for local deployment.

## Dataset

Trained on the public ["Solar Panel Inspection" dataset](https://huggingface.co/datasets/metalmerge/solar-panel-inspection)
(same 6 classes as the original script: Clean, Bird-drop, Dusty,
Electrical-damage, Physical-Damage, Snow-Covered), downloaded from
Hugging Face into `data/SolarPV_Images/`.

## Project layout

```
app/
  train.py     - trains the CNN, saves app/model/solar_fault_classifier.h5
  main.py      - FastAPI service: GET / (upload UI), POST /predict
data/
  SolarPV_Images/     - raw dataset (class subfolders)
  Processed_Dataset/  - train/val split generated by train.py
Dockerfile
requirements.txt
```

## Run locally (no Docker)

```bash
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt

python app/train.py          # trains and saves app/model/solar_fault_classifier.h5
uvicorn app.main:app --host 0.0.0.0 --port 8000
```

Then open http://localhost:8000 and upload a panel photo.

## Run with Docker

The model must be trained first (Docker build only packages the already-trained
`.h5` file, it doesn't train inside the image):

```bash
python app/train.py
docker build -t solar-fault-detector .
docker run --rm -p 8000:8000 solar-fault-detector
```

Then open http://localhost:8000.

## API

`POST /predict` — multipart form upload, field name `file`, image content type.

```bash
curl -F "file=@panel.jpg" http://localhost:8000/predict
```

```json
{"label": "Defect", "raw_score": 0.87, "confidence": 0.87}
```

`GET /health` — liveness/model-loaded check.

## Notes

- Binary classifier only (Clean vs Defect), matching the original script.
  It does not distinguish between fault *types* even though the training
  data has per-fault-type folders.
- Runs on CPU (`tensorflow-cpu`); no GPU is required or used.
